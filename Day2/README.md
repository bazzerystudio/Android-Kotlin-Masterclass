## 📱 ฟีเจอร์หลักในแอปพลิเคชัน (Key Features)

แอปพลิเคชันถูกจัดกลุ่มออกเป็น 3 แท็บหลักผ่าน Bottom Navigation Bar เพื่ออำนวยความสะดวกในการเรียนรู้:

### 1. 🎮 เป่ายิ้งฉุบ (Rock Paper Scissors Game)
- **Visual Mode**: โหมดการเล่นผ่านการคลิกการ์ดสัญลักษณ์ (ค้อน 🪨, กระดาษ 📄, กรรไกร ✂️) พร้อมแอนิเมชันตอนคอมพิวเตอร์สุ่มเลือก (Thinking state) และแสดงผลลัพธ์แพ้ชนะอย่างสวยงาม
- **Text Validation Mode (จำลองการรับค่าคีย์บอร์ด)**: ผู้เล่นต้องป้อนข้อความ "Rock", "Paper" หรือ "Scissors" ด้วยตนเอง เพื่อทดลองและจำลองตรรกะ Validation ตามบทเรียน (หน้า 18) หากพิมพ์ตัวสะกดผิดหรือใช้พิมพ์เล็ก-ใหญ่ผิด (เช่น "dog" หรือ "rock") ระบบจะดักจับและแจ้งเตือนข้อผิดพลาดทันทีโดยไม่ให้เกมเกิดความเสียหาย
- **Game History & Scoreboard**: ระบบบันทึกจำนวนคะแนน ชนะ/แพ้/เสมอ และแสดงผลลัพธ์ย้อนหลังผ่านกล่องประวัติการเล่น (Game Loop History) เพื่อสาธิตคอนเซปต์ While Loop

### 2. 📟 คอนโซลจำลอง (Console Simulator)
- **จำลองการทำงานคอนโซลเต็มรูปแบบ**: หน้าจอจำลองรันโค้ดภาษา Kotlin ของเกมเป่ายิ้งฉุบแบบ Loop คอนโซลสมบูรณ์ตามตัวอย่างโค้ดจริง
- **การพิมพ์โต้ตอบ**: มีการรับค่าผ่าน TextField และปุ่มส่ง (Send) แสดงผลลัพธ์ย้อนหลังทางหน้าต่าง Terminal สีดำ/ตัวอักษรเขียวตรงไปตรงมาเหมือนรันโปรแกรมบนคอมพิวเตอร์จริง

### 3. 📚 สนามเด็กเล่น Kotlin (Kotlin Basics Sandbox)
บอร์ดอินเตอร์แอคทีฟจำลองการทดสอบโค้ดตรรกะย่อยในแต่ละ Module ของบทเรียน ประกอบด้วย:
- **Module 1: Hello World**: กดปุ่มเพื่อรันคำสั่งแสดงผล `println()` ในกล่องจำลอง Console สีดำ/ตัวอักษรเขียว
- **Module 2: Variables (`val` vs `var`)**: บอร์ดทดลองเปรียบเทียบกล่องตัวแปรแบบแก้ไขไม่ได้ (`val`) และกล่องที่อนุญาตให้แก้ไขได้ (`var`) โดยผู้ใช้สามารถกดเพิ่มคะแนนเพื่อดูพฤติกรรมจริงของหน่วยความจำ หากพยายามแก้ไขตัวแปร `val` ระบบจะจำลองแสดงข้อความ Compiler Error เพื่อให้ผู้เรียนเกิดความเข้าใจอย่างถ่องแท้
- **Module 3: Booleans, Chars & Strings**: บอร์ดทดลองกดสลับสถานะ Boolean ตัวแปร `isSunnyDay` เพื่อดูผลของการกลับค่าความจริงด้วยตัวดำเนินการนิเสธ `!` และทดลองพิมพ์ชื่อผู้เล่นเพื่อประมวลผล String Templates ใน Console จำลองแบบ Real-time
- **Module 4: If-Else & Crash Prevention (วัยและปีเกิด)**: ช่องรับค่าอายุเพื่อประเมินความถูกต้องและแยกทางเลือกช่วงอายุแบบ `if-else if-else` รวมถึงตรวจสอบคำเตือนของ Mentor (Mentor's Warning หน้า 10) โดยหากกรอกข้อมูลที่ไม่ใช่ตัวเลข (เช่น ตัวอักษรภาษาอังกฤษ) ระบบจะดักจับด้วย Try-Catch บล็อกเพื่อป้องกันแอปพลิเคชันแครช (Crash Prevention)

## 🛠️ โครงสร้างซอร์สโค้ด (Source Code Directory)

โค้ดทั้งหมดถูกออกแบบภายใต้หลักสถาปัตยกรรม Clean Architecture และจัดแบ่งโฟลเดอร์ดังนี้:

```text
app/src/main/java/studio/bazzery/androidmasterclassday2/
│
├── MainActivity.kt               # หน้าหลักที่คุมส่วนควบคุม Scaffold & Navigation Tabs
│
├── ui/
│   ├── theme/
│   │   ├── Color.kt              # กำหนดชุดสีของ Material Design 3
│   │   ├── Theme.kt              # ตัวปรับธีมระบบหลัก (รองรับ Dynamic Color และ Dark Mode)
│   │   └── Type.kt               # สไตล์ฟอนต์และการจัดตัวอักษร
│   │
│   ├── components/
│   │   └── SharedComponents.kt   # Composable ส่วนกลางที่ใช้ร่วมกัน เช่น CodeSnippet
│   │
│   └── screens/
│       ├── RpsGameScreen.kt      # ส่วนติดต่อผู้ใช้งานและตรรกะการเล่นเกมเป่ายิ้งฉุบทั้งหมด
│       ├── ConsoleSimulatorScreen.kt # ส่วนติดต่อผู้ใช้งานและตรรกะจำลอง Loop คอนโซลสมบูรณ์แบบ
│       └── KotlinSandboxScreen.kt # ส่วนติดต่อผู้ใช้งานและตรรกะ Sandbox สำหรับ Module 1-4
```

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (How to Run)

### ความต้องการของระบบ (Prerequisites)
1. **Android Studio** เวอร์ชั่นล่าสุด (เสถียร)
2. **JDK 17** ขึ้นไป
3. **Android SDK Level 33** เป็นอย่างน้อย (`minSdk = 33`, `targetSdk = 36`)

### ขั้นตอนการรัน
1. เปิดโปรแกรม **Android Studio**
2. เลือก **Open** และนำทางไปยังโฟลเดอร์:
   ```text
   /Users/bz/Works/CourseTrainnig/Android Master Class/Sources/Day2
   ```
3. รอให้ Gradle Sync สำเร็จเสร็จสิ้น
4. เลือก Emulator หรือเสียบอุปกรณ์ Android จริงที่เปิดโหมด Developer Option / USB Debugging แล้ว
5. กดปุ่ม **Run** (ไอคอนสามเหลี่ยมสีเขียว) บนแถบเครื่องมือด้านบน เพื่อติดตั้งและใช้งานบนเครื่องจำลอง/โทรศัพท์ทดสอบได้ทันที
